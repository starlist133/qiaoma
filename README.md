# 上海敲麻 · 百搭版

纯前端实现的上海敲麻（百搭）四人局模拟，你 vs 3 个 AI。无依赖、无构建，打开即玩。

在线玩：https://starlist133.github.io/qiaoma/

## 规则要点

- **牌张**：万/条/筒各 36 张（共 108），风牌东南西北 16 张，花牌 20 张（中发白 12 + 春夏秋冬梅兰竹菊 8）。中发白按花牌处理：摸到即补花、计 1 花、不参与组牌。
- **百搭**：开局翻「引导牌」，其下一张为百搭（九→一，北→东；翻到花牌则百搭为东风）。百搭可替代任意牌组面子或将牌。
- **必须先敲（报听）才能胡**。敲后牌型锁定，摸什么打什么，见胡必胡。
- **不能吃**，只能碰、杠。胡牌方式：自摸、抓铳、抢杠。
- **无七对**。无花牌（无花果）计 10 花。

## 计分

总分 = 花数 × 2^番数 × 倍数

**花数**：底花 1；花牌每个 +1；风刻 +1、风明杠 +2、风暗杠 +3；序数牌明杠 +1、暗杠 +2；百搭 +1；无花果直接记 10 花。

**番种**：门清 1、碰碰胡 1、混一色 1、大吊车 1、杠开 1；清一色 2、混碰 2；清碰 3。1 番 = ×2。

**倍数**：抢杠 ×3、开宝 ×2、荒番每积累一级 ×2。

**结算**：自摸三家各付；点炮由放铳者独付；抢杠由被抢杠者付。

## 操作

- 点手牌打出；摸牌后可点「敲」锁定听牌；有碰/杠/胡机会时底部会出现按钮。
- 右上「规则」看完整规则，「设置」可开关中发白算花、百搭、是否允许吃等。
- 手机竖屏可用，牌面会自动缩放。
